# Concept Archive

These are design references, not implemented software screenshots. Sample tickets, countdowns, and repository values are fictional. The written specification governs when example values differ across images.

## Original five explorations

1. Daily Desk — warm Today, priorities, Day Agenda, persistent timer; contributed the Home structure and Personal/Team placement.
2. Mission Control — dense dark ticket console, compact rail, contextual navigation and inspector; contributed the shell and ticket details.
3. Flow Board — Kanban tickets and lightweight weekly planning; contributed the Projects ticket board.
4. Rhythm — calendar-first work sessions; contributed agenda/work-block thinking.
5. Project Atlas — goals, milestones, dependencies, project map; contributed the large-project Map.

## Combined designs

6. **Graphite / Cyan — SELECTED.** Crisp technical utility with Today, ticket Kanban, project map, inspector, timer, quick add, and three event countdowns.
7. Charcoal / Amber / Sage — retained as an alternate theme/style reference.

The owner wants the selected direction expanded into a full dashboard app with a roomier layout and adjustable smaller text. Do not reproduce the compressed three-screen sheet as one app screen.
